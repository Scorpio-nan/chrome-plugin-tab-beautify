## 4. 实施约定

- 小组件统一走 `widgets/registry.tsx` 注册并同步 `lib/types.ts` 的 `WidgetId`；不新增第二套注入机制。
- 状态只进 `chrome.storage`：小配置 `sync.config`，大对象 `local`；跨页面用 `storage.onChanged` 同步。
- 树编辑逻辑写进 `lib/nav.ts` 的纯函数；id 在 reducer 外生成。
- 远程数据统一在 `entrypoints/background.ts` 取，集中在后台做缓存与降级；**禁止调用任何 `*.wetab.link` 接口**。
- 权限最小化：新增权限必须在审核表写明理由，能走可选权限就不进 `permissions`。

## 5. 验收标准

1. 上游有的开关/菜单项，本地有同义项，文案与默认值一致。
2. 交互闭环：新建 → 编辑 → 删除 → 刷新后保持 → 换页面实时同步。
3. 断网可用性不低于上游：纯本地模块断网全功能可用，远程模块有占位降级。
4. 每个模块完成后 `npm run compile` 通过，并在已加载的扩展里手工验证。
